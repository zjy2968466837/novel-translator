# UI Spec (Markdown)

## IA
1. 首页/任务列表
2. 新建任务
3. 任务详情（进度+章节）
4. API 调试面板
5. 纠错重传中心
6. 设置（Provider/模型/并发/路径）

## 任务详情
- 顶部：任务状态、总进度、预计剩余时间
- 左侧：章节列表（状态筛选：成功/重试中/失败）
- 右侧：章节原文/译文对照 + 术语命中提示
- 底部：暂停/继续/重试失败章节/导出日志

## API 调试面板
- 过滤：章节ID、时间范围、状态码、provider
- 列表：请求ID | 章节 | 耗时 | token | 状态
- 详情：Request(JSON) / Response(JSON) / Error Trace
- 操作：复制、导出、脱敏切换

## 纠错重传中心
- 检测规则开关：缺段/术语/HTML结构/长度异常
- 失败原因聚类统计
- 批量动作：按原因一键重传
- 重传策略：普通/严格/保守
